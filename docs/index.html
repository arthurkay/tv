Most TVs and boxes from 2019 on are arm64. Older or budget sticks need the armeabi-v7a build (26 MB) instead — check with adb shell getprop ro.product.cpu.abi, or just try arm64 first.

INSTALLING IT

  1. On the TV, open Settings → Apps → Security & restrictions → Unknown sources and allow whichever app you will download with (a browser, a file manager, or a downloader app).
  2. Open that app and enter the address above. Most Google TV devices ship without a browser or file manager, so install one from the Play Store first.
  3. Pick Download the APK, then open the downloaded file and confirm the install. Vieo TV appears in your Apps row.

On a computer instead? adb connect <tv-ip>:5555 then adb install -r vieo-tv.apk. The full runbook covers pairing, logs and the errors worth knowing about.

Signed with a debug key, so this is for your own devices — Android will refuse to upgrade it over a build made on a different machine.
